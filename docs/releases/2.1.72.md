# JustEnoughGuide 2.1.72 — Offline profile history repair

## Change

Fix the offline-profile `NullPointerException` in `GuideHistoryPatchListener` that prevented its normal guide-history callback from running. The listener now uses the supplied profile, installs the existing JEG history implementation, and logs its UUID without dereferencing a live Player.

The player-join path, event priority, guide controls, item and research IDs, recipes, bookmark/history formats and scheduler submissions are unchanged. There is no data migration, configuration reset or new dependency.

After publication, use `SF_JustEnoughGuide2.1.72.jar`. Stop the server, back up the existing installation and replace the old JEG JAR without keeping duplicate JEG files. Preserve the existing configuration and data folders, then restart normally.

This standalone patch does not alter the published Slimefun Legacy 4.1.70 core, revision-125 addon ZIP or optional resource pack. Bundle integration is a separate source-pinned validation step; until that step is published, revision 125 still contains JEG 2.1.71.

# Security Policy

## Supported Version

The latest release of SF_JustEnoughGuide is the supported version.

Use the Releases page in this repository to obtain the current build.

## Reporting a Vulnerability

Please open a GitHub issue in `wickidcow/SF_JustEnoughGuide` with enough detail to reproduce the problem.

For vulnerabilities involving item duplication, storage corruption, permission bypass, recipe completion, machine input filling, or guide inventory manipulation, include:

- Minecraft/server version;
- Slimefun or Slimefun Legacy version;
- SF_JustEnoughGuide version;
- relevant addon versions;
- exact reproduction steps;
- logs or stack traces when available.

Do not include private server credentials, tokens, or other secrets.

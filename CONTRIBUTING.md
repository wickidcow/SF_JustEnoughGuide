# Contributing

Contributions to SF_JustEnoughGuide are welcome.

Please open an issue or pull request in this repository and describe the problem, compatibility concern, or proposed change clearly.

For Slimefun Legacy integration work, preserve these rules:

- do not bypass Slimefun Legacy protection or transaction safeguards;
- prefer supported public APIs over reflection;
- keep player/admin-facing text English;
- preserve backwards compatibility with upstream Slimefun when practical;
- keep the distributable artifact named `SF_JustEnoughGuide<version>.jar`.

Please follow the repository Code of Conduct in all project interactions.
